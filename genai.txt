TicketWave: Ticket Booking System (Travel & Events)
🎯 Overview
The Ticket Booking System supports discovery, seat selection, dynamic pricing, booking, and payment flows for travel (flights, buses, trains) and events. It handles inventory, holds, cancellations/refunds, and notifications, with role-based access and partner/vendor portals.

🔌 Backend API Endpoints

Authentication & Users
POST /api/register – Register user
POST /api/login – Authenticate and return JWT
GET /api/users/{id} – Retrieve user (admin)
GET /api/audit – Audit logs (admin)

Catalog & Inventory
GET /api/search – Query routes/events
GET /api/schedules/{id} – Schedule details
GET /api/schedules/{id}/seats – Seat availability
POST /api/schedules – Create schedule (operator)
PUT /api/seats/{id} – Update seat status

Booking & Payment
POST /api/bookings – Create booking and hold seats
PUT /api/bookings/{id}/confirm – Confirm booking on payment
POST /api/bookings/{id}/payments – Record payment
POST /api/bookings/{id}/refunds – Initiate refund
GET /api/bookings/{id} – Booking details
